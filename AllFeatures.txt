Fantasy Baseball Draft Aide - Group 3

Planned semester features:
1. List MLB teams.
2. List players on a team.
3. Search for a player by name.
4. Initialize the database from MLB batting and pitching data.
5. View a fantasy team.
6. Draft a player (IDRAFT and ODRAFT).
7. Check duplicate picks.
8. View player batting and pitching statistics.
9. Rank undrafted pitchers (POVERALL).
10. Rank undrafted non-pitchers (OVERALL).
11. Print/update current draft state.
12. Sort players by overall score.
13. Update OVERALL/POVERALL based on evaluation functions (EVALFUN and PEVALFUN).
14. Serialize the database to support saving and restoring.
15. Save the current draft.
16. Restore the draft state from a filename.fantasy.txt file.
17. Show available commands and their syntax (help).
18. Quit the program.
19. Run the FantasyDraft command prompt/input loop.
